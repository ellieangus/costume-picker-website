# Spooky Costume Picker

A small Halloween-themed static website (HTML, CSS, JavaScript) hosted on Amazon S3.

- `index.html`: page structure (S3 index document)
- `styles.css`: spooky styling and flying bat animation
- `script.js`: random costume picker and Halloween countdown
- `error.html`: custom 404 page (S3 error document)

Preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
